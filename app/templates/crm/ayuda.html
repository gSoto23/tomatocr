Guía corta para el equipo comercial. El piloto se lleva aquí, en Clientes: {{ period.label }}.

{% call box("1. Tu día empieza en el Dashboard") %}

Ahí ves tus próximos pasos vencidos y los de hoy. La regla es simple: ninguna oportunidad abierta sin próximo paso y sin fecha.

{% endcall %} {% call box("2. De dónde salen los prospectos") %}
  • Los buscás vos (LinkedIn, correo, SICOP, referidos, visitas): los registrás como en el punto 3.
  • Llegan solos por el formulario de tomatocr.com (y más adelante de darboles.com). Entran como oportunidad en Prospecto con el próximo paso "Responder la solicitud" para ese día.
  • El admin los reparte. Cuando te asigna una oportunidad te llega un correo con el enlace. Respondé ese mismo día.
{% endcall %} {% call box("3. Registrar un prospecto nuevo") %}
  1. Buscá primero en Cuentas: la empresa puede existir ya (como cliente, ex-cliente o prospecto de otro).
  2. Si no está: Nueva cuenta. Si el sistema avisa que hay cuentas parecidas, revisalas antes de crear otra.
  3. En la cuenta, pestaña Contactos: agregá a la persona con su cargo, correo y teléfono.
  4. Pestaña Oportunidades: creá la oportunidad con su motor, tipo Nuevo y el próximo paso con fecha.
{% endcall %} {% call box("4. Las etapas") %}
  • Prospecto: la empresa está identificada y le hiciste (o vas a hacer) el primer contacto.
  • Respuesta: te contestó, aunque sea para decir "ahora no".
  • Reunión: hubo una reunión, llamada formal o visita.
  • Propuesta: se envió una cotización. Pasa sola al guardar una cotización hecha con "Crear cotización".
  • Ganado: el cliente aceptó. El admin la liga al proyecto con "Marcar ganada".
  • Perdido: no va a avanzar. El sistema pide el motivo; escribilo claro, sirve para aprender.

Cada cambio de etapa queda en el historial de la cuenta.

{% endcall %} {% call box("5. Seguimientos") %}

Cada llamada, correo, WhatsApp, visita o reunión se registra en la cuenta con Registrar seguimiento. Al final de cada contacto, actualizá el próximo paso y su fecha.

{% endcall %} {% call box("6. Cotizar") %}

Desde la oportunidad, Crear cotización abre el cotizador con la cuenta y el contacto ya puestos, y deja la cotización ligada a la oportunidad. No hagas la cotización por fuera: no quedaría ligada ni contaría en el embudo.

{% endcall %} {% call box("7. Qué cuenta para las metas del piloto") %}
  • Cuentan las cuentas con una oportunidad de tipo Nuevo creada dentro del periodo ({{ period.label }}).
  • Cuenta la etapa más alta alcanzada: si una oportunidad llegó a Reunión y después se perdió, sigue contando hasta Reunión.
  • Las renovaciones y ampliaciones de clientes actuales no cuentan para las metas; igual se trabajan y aparecen en la lista.
  • Metas del piloto: {% for row in funnel %}{{ crm_labels.stage[row.stage] }} {{ row.target }}{{ ', ' if not loop.last }}{% endfor %}.
{% endcall %} {% call box("8. Qué podés ver y editar") %}

Ventas ve todas las cuentas, sin datos de finanzas. Editás las tuyas y las que no tienen dueño (al editarlas quedan a tu nombre). Reasignar, fusionar duplicados, cambiar metas y marcar ganada lo hace el admin.

{% endcall %} {% call box("9. Datos personales") %}

Si una persona pide que borremos sus datos, avisale al admin: en el sistema hay una opción para hacerlo sin perder el historial de la cuenta. Solo se contacta por correo o WhatsApp a quien lo pidió o nos dio sus datos para eso.
