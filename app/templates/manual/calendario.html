{% extends "manual/_layout.html" %} {% block manual %} {% call m.section("que-es", "Qué es") %}

El Calendario organiza quién trabaja en qué proyecto cada día y con qué tareas. Cada día asignado a una persona es una asignación. Las asignaciones aparecen en el Dashboard de cada trabajador y, cuando se confirman sus horas en Planilla, se pagan y cuentan como costo del proyecto.

Quién lo usa: {{ m.roles(["admin", "supervisor", "worker"]) }}. El admin y el supervisor ven y organizan las asignaciones de todo el equipo; cada trabajador ve solo las suyas.

En el celular el calendario se abre directo en la lista de la semana, que se lee mejor en pantalla chica.

  • Un rango de fechas crea asignaciones separadas: después se editan o borran una por una. Si no trabajan fines de semana, asigná por semana laboral o borrá esos días.

Las asignaciones las hace el supervisor o el admin. Si falta la tuya o está en otro día, avisales.

{% endif %} {% endcall %} {% call m.section("editar", "Cambiar o borrar una asignación") %} {% if user.role in ['admin', 'supervisor'] %}

Tocá la asignación en el calendario. Podés cambiar la fecha, el proyecto, el trabajador o las tareas y tocar Guardar. Eliminar pide confirmación (Sí, Eliminar).

{% call m.warn("Al editar se desmarcan las tareas") %}

Guardar una asignación vuelve a crear sus tareas: las que el trabajador ya había marcado como hechas quedan sin marcar. Si ya las marcó, evitá editarla. Y si borrás una asignación con horas ya confirmadas, esas horas se van de la planilla.

{% endcall %} {% else %}

No podés cambiar tus asignaciones; pedíselo al supervisor.

{% endif %} {% endcall %} {% call m.section("tareas", "Marcar las tareas hechas") %} {% if user.role == 'worker' or user.role == 'admin' %} {{ m.shot("calendario/tareas.webp", "Tareas de una asignación", "Las tareas de una asignación, desde el trabajador.", mobile=True) }} {% endif %}

El trabajador toca su asignación (en el Calendario o en Gestionar del Dashboard) y marca cada tarea al terminarla: se guarda sola y aparece tachada. Ir al Proyecto abre la ficha del proyecto para registrar la bitácora del día.

{% endcall %} {% call m.section("horas", "Las horas") %}

El Calendario no pide horas: cada asignación empieza con 8 horas y 0 extra, sin confirmar. Las horas reales y las extra se revisan y confirman en Planilla → Aprobar Horas {%- if user.role != 'client' %} (ver el capítulo Planilla){% endif %}. Solo las horas confirmadas se pagan.

{% endcall %} {% call m.section("preguntas", "Preguntas frecuentes") %}
{% call m.faq("¿Se puede arrastrar una asignación a otro día?") %}

No. Abrila, cambiá la Fecha Inicio y guardá.

{% endcall %} {% call m.faq("¿Dónde elijo la sede?") %}

El Calendario no tiene sede. Escribila en el título o la descripción de la tarea si hace falta; la sede se elige al registrar la bitácora.

{% endcall %} {% call m.faq("Asigné un rango y me creó también sábado y domingo") %}

Así funciona el rango. Borrá esos días uno por uno, o la próxima vez asigná de lunes a viernes.

{% endcall %} {% call m.faq("El calendario muestra el usuario y no el nombre") %}

Es así: cada asignación dice el proyecto y, entre paréntesis, el usuario con el que la persona entra al sistema.
